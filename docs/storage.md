# 配置与工作目录

## 数据分类

| 类别 | 内容 | 位置 |
| --- | --- | --- |
| 程序 | EXE、嵌入语言 / 图标 / 字体 / 许可 | 用户放置 EXE 的位置，不向旁边写配置 |
| 配置和状态 | 语言、主题、偏好、配对、任务元数据、目录引用和少量日志 | LocalAppData 下的 MakudonShuttle 目录 |
| 工作文件 | ZIP、原图、正文、打包材料、解压结果、接收 / 生成暂存 | 用户明确选择的工作目录或本次保存位置 |

设置只存工作目录引用，不存文件本体。任务记录可保存位置、摘要和状态，不包含正文、ZIP 字节或图片。任务必要的路径是本机元数据；日志和诊断不自动携带私人完整路径。

## Windows 配置

通过系统 Known Folder API 获取 FOLDERID_LocalAppData，例如 %LOCALAPPDATA%\MakudonShuttle，保存 settings.json、devices.json、有界任务记录及小体积诊断。不拼用户名，不要求管理员权限。

设备和任务不应漫游，语言和主题也统一 LocalAppData，以免引入不必要的多目录策略。[Microsoft Known Folders](https://learn.microsoft.com/en-us/windows/win32/shell/knownfolderid)

TLS 私钥由平台安全能力或当前用户 DPAPI 保护，不放进 EXE 或明文日志。复制 EXE 到其他 PC 不搬迁配置和信任关系，必要时重新配对。

## 工作文件

首次输出时选工作目录，之后可沿用或另选。系统“文档”可以是选择器起点，但不在用户确认前自动创建备份目录。支持用户选择其他磁盘、外置盘或现有目录。

工作目录不可等于或位于配置目录内。检查需要处理规范化、junction / reparse point，不能只比字符串前缀。位置断开、移走或只读时要求重选，不回退到配置目录写大文件。

可在工作目录的 .makudon-shuttle/transfers/<id>/ 暂存，完成后发布到指定目标；不把大 ZIP 丢进配置目录的 cache 子目录。中断后显示实际残留与清理入口。打包、解压先估算空间，实际 I/O 失败仍保留源文件和已有成功输出。

## 生命周期

- 更换工作目录不移动或删除旧文件。
- 清空记录只删元数据，不删被引用 ZIP 和文稿。
- 重置偏好、忘记设备不影响工作文件。
- 清理只处理经核实、应用创建且未发布的受控任务材料。
- 不扫描整个工作目录按扩展名猜测可删内容。
- 多实例对配置和任务需要互斥，不能同时发布同一输出。

免安装单 EXE 是分发方式，不表示单文件容纳全部用户数据，也不表示退出后无配置痕迹。
