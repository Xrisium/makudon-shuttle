# Makudon Shuttle 产品约定与开发任务

更新：2026-11-26。当前只讨论、修改文档和制作交互例图，不开始产品编码。

## 已确定的产品边界

- 只备份当前文稿库，ZIP 格式、范围和导入行为与 Makudon 自带系统一致。
- 两端是 ZIP 文件收发工具；不浏览手机私有目录、不读取文稿树、不远程恢复或调试设备。
- 首先交付离线与 LAN，USB 和蓝牙后续补齐；macOS 和其他架构留作远期候选。
- Windows 10 x64 为首要开发和验收环境，不将 Windows 11 作为前提。
- 单 EXE 免安装分发，配置和本机状态存 LocalAppData；ZIP、文稿、解压结果和大体积暂存放在用户工作目录。
- 视觉尽量严格跟随 Makudon 当前实现，不能为了轻量擅自更换字体和设计语言。
- 不做 ZIP 口令加密；用户已进一步确认，传输使用标准 TLS。
- 免费开源、MIT，不购买代码签名、不引入收费服务或云账户。
- Android 工具链和设备操作参照 Makudon 当前本地配置，历史设备不固定绑定。

## 操作流程

离线支持 ZIP 库存与兼容预检、PC 文稿目录打包、安全解压到选定工作位置。显示文件层级、数量、大小、跳过项及冲突，不改源文件、不执行包内内容、不跟随链接。

手机发送：用户在手机导出并发送，或选择已有 ZIP，PC 确认接收并保存。

PC 发送：选择 ZIP，手机确认接收并保存；用户另点“导入文稿库”，进入手机现有恢复页。PC 只显示“已发送到手机”，不跟踪或宣称“已恢复”。

传输不隐式解压、规范化正文、跳过文件或执行恢复。兼容预检独立于原字节传送，手机原有 ZIP 验证具有最终判断权。

## 文件通信协议

仅包含协议版本、传输能力、配对、文件提议、接受 / 拒绝、数据块、取消、校验、已保存回执和结果查询。首版单设备单任务，控制帧和内存缓冲有界，ZIP 不转 Base64。

文件提议包含传输 ID、显示名称、字节数、SHA-256，接收方自行决定本地路径。协议版本独立于应用版本；不传文稿树、库指纹、节点 ID、恢复模式、冲突、快照或远程命令。

“已保存”须完成关闭文件、摘要校验和不覆盖发布。回执丢失按相同 ID 和摘要查询，避免盲目重复保存；同 ID 不同内容拒绝。可以先完整重传，断点续传为候选。恢复与收件分离，不再需要为远程恢复修改手机库指针。

标准 TLS 配合限时邀请与设备身份，接收仍由本地确认。忘记设备不删除 ZIP。默认按需监听，不全网扫描、不遥测、不云转发、不自动更新，日志不含正文、令牌与私钥。

## ZIP 和文件安全

| 项目 | 当前手机基线 |
| --- | --- |
| 输入 ZIP / 累计展开 | 各 512 MiB |
| 条目 / 层级 | 20,000 / 128 |
| 中央目录 | 16 MiB，分配前检查 |
| 恢复后节点 / 索引 | 10,000 含根 / 4 MiB，包装目录占节点 |
| 正文 | 严格 UTF-8，100,000 码点且 ≤ 1 MiB；导入去 BOM 并规范化换行 |
| 图片 | JPEG / PNG / 静态 WebP，每张 ≤ 20 MiB / 1 亿像素 |
| 空内容 | 空文件可用，只有空目录的 ZIP 不恢复，空库可导出 |

传送保持 ZIP 原字节。PC 打包按普通相对路径，预检 / 配对元数据不塞入归档。普通 ZIP 不保证都能导入 Makudon。

解压拒绝路径穿越、绝对路径、UNC / 盘符、特殊文件、重复路径与文件目录冲突。Windows 保留名、ADS、末尾点 / 空格、大小写 / Unicode 碰撞和长路径须先显示。不能静默改名；改名须保证 Markdown 相对图片引用仍可用，无法保证则拒绝该方案。

在工作目录写独立 .partial，校验后不覆盖发布；各文件系统单测，不承诺跨卷原子和断电零丢失。配置清理不能删工作文件。

## 技术候选

Rust + egui/eframe 的采用条件是视觉一致性、中文、无障碍和 Windows 10 验证通过，不能直接使用默认 egui 风格。只建立必要的控件皮肤和小范围职责，不预建通用同步框架。

起步一个 Cargo package，区分 UI、归档、收发、配置、平台适配。TLS、ZIP、JSON、Windows API、mDNS 库按需要引入，锁稳定版本和特性，说明用途、许可与体积。若不能达到设计要求，在产品编码前重比 Tauri 等候选。

轻量通过参考机测量 EXE、依赖、启动、内存、字体和图形后端；不因压缩体积牺牲字体覆盖或中文显示。
