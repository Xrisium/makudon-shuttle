# Agent 与开发约定

## 当前范围

仅讨论、改文档和制作可交互例图。不建产品工程、不安装依赖、不构建、不操作手机。例图不代表 egui 已实现或技术验收通过。

## 接续

1. 读文档索引、状态和相关专题，核实分支和已有改动。
2. 默认 main 串行工作，不自行开分支或并行代理。
3. 用户最新决定优先，任务清单不代表编码授权。
4. 阅读 Makudon 遵循其 AGENTS.md 和索引；本轮不修改该仓库。

## 文档与产品

- README 是产品窗口，任务、状态、工具链和 Agent 资料放 docs。
- 任务只描述工作与条件，不加入开发日期安排、时长估算或截止承诺。
- ZIP 是两端契约，不扩成设备调试、私有文稿树读取、远程恢复或删除同步。
- 未来先做最小链路，不预建空接口群或通用同步框架。
- 界面少解释、少重复；必要风险与失败动作保留，技术原理放文档。

## 环境

Android 遵循 Makudon docs/development.md、.local/android.json 和 scripts/android.ps1 的解析结果。当前 JDK 17、SDK 36、AVD Android_API_36，复用现有环境，不另装 Android Studio 或重复工具链。

设备遵循其 docs/device-policy.md，模拟器优先，真机每次重新识别。历史 HUAWEI LIO-AN00 / API 31 不是固定目标，本轮不运行 adb、不安装、不抓真机截图。后续硬件测试按必要范围集中安排，不能以 ADB 通道代替正式 USB 链路。

Rust 工具链未选定，不为文档讨论自行安装。Windows 10 x64 优先；先检查现有能力，再提出新增依赖。

## 检查与 Git

文档检查事实、链接、范围和差异，无须产品构建。例图检查主要交互、主题、窄宽和可访问标签，不将浏览器效果写成 egui 验证结果。未来 Android 修改按 Makudon 当前测试指南选针对性检查。

保留用户未提交改动，不自动 push、改全局配置或操作其他仓库分支。本地提交按当前仓库适用约定与用户授权处理，不把 Makudon 的规则扩大为修改其仓库的授权。
